# 黑帧空间 (Black Frame Void) 参考图提示词

## 场景设定

- **本质**：现实世界被“暂停”后露出的电影底层剪辑层。非恐怖异空间、非恶魔鬼片，而是现实世界的某一部分被抽去饱和度、凝固成静止胶片。
- **视觉特征**：
  - 现实场景轮廓依然存在（如卧室、街道、十字路口），但所有人与非关键物体像静止静帧一样冻结。
  - 冷调灰蓝色彩，画面边缘带有淡淡胶片齿孔与裁切裂口。
  - 空间中漂浮着极细的暗银色微光时间轴记忆胶片光带（Memory Film Strip）。
- **画风规范**：
  - 电影级厚涂动漫风格，Makoto Shinkai 式精致背景与冷色调光影。
  - 9:16 竖屏电影构图。
