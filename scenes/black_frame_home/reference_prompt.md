# 林默公寓 (Lin Mo's Apartment) 参考图提示词

## 场景设定

- **本质**：林默日常生活的单身公寓，真实生活感强，整体呈现出冷淡、安静、略带孤独与回忆缺失的质感。
- **空间构成**：
  - `home_bedroom_night`：夜间卧室，单人床，床头微弱暖光台灯与窗外冷蓝色夜景对比。
  - `home_dining_table`：餐桌近景，桌上并排放着两个杯垫，却只有一个水杯。
  - `home_wardrobe`：打开的衣柜，右半侧空空荡荡，挂钩与空衣架。
  - `home_living_room`：安静的客厅，布艺沙发，茶几上整齐摆放着笔记本与水杯。
- **画风规范**：
  - 电影级写实厚涂动漫背景（Cinematic anime background art, Makoto Shinkai interior aesthetic）。
  - 低饱和冷灰蓝与局部室内暖光的层次对比，细节丰富细腻。
  - 9:16 竖屏构图。
