# 街角花店 (Corner Flower Shop) 参考图提示词

## 场景设定

- **本质**：林默通勤路过的街角花店，橱窗里盛开着清晨采摘的白色郁金香，是贯穿林默与许知遥记忆的核心情感锚点。
- **视觉特征**：
  - 暖色木质门框，干净透明的大玻璃橱窗。
  - 橱窗内被柔和暖光灯照亮的白色郁金香花束，花瓣娇嫩，绿叶鲜润。
  - 傍晚/清晨时分，暖黄色室内光与室外清冷街道形成鲜明反差。
- **画风规范**：
  - 电影级厚涂动漫场景（Makoto Shinkai lighting, Studio Ghibli warmth, cinematic anime still）。
  - 9:16 竖屏构图。
