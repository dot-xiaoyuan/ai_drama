# 十字路口 (City Crosswalk) 参考图提示词

## 场景设定

- **本质**：阴天城市主干道十字路口，人流与车流在此交汇。既是现实救人的危险发生地，也是黑帧首次被察觉的定格舞台。
- **视觉特征**：
  - 阴天漫射光，湿润的柏油路面与清晰的白色斑马线。
  - 现实版：人群与车辆穿梭，红绿灯亮起。
  - 黑帧版：所有人与车像胶片一样静止冻结，色调抽离为冷灰蓝，中央剪辑员黑影出现。
- **画风规范**：
  - 电影级动漫街景（Cinematic anime cityscape, Makoto Shinkai urban street aesthetic）。
  - 低饱和冷色调，丰富的街道建筑与雨后/阴天空气感。
  - 9:16 竖屏构图。
