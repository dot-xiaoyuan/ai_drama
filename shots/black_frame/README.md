# 《黑帧》Shot 索引


每个 shot 是一个 5 秒 Seedance 素材单元，最终剪辑可只取其中 2～4 秒。

## s01 卧室冷开场
- `black_frame/s01_shot_01`：林默夜里躺在床上，手机微光照亮疲惫的脸，他抬手准备关灯。
- `black_frame/s01_shot_02`：房间灯光已经熄灭，林默闭上眼，完全没有意识到刚才发生过异常。
- `black_frame/s01_shot_03`：手机屏幕在黑暗卧室里短暂亮起，具体时间由后期叠加，画面极静。

## s02 十字路口救小孩
- `black_frame/s02_shot_01`：白天城市十字路口，林默站在人群中等红灯，年轻妈妈牵着小男孩在他旁边。
- `black_frame/s02_shot_02`：绿灯亮起，人群开始过街，小男孩稍微落后，左转汽车从远处接近。
- `black_frame/s02_shot_03`：黑帧内部，十字路口所有人和车都静止，林默惊讶地看向小男孩。
- `black_frame/s02_shot_04`：黑帧内部，一个负空间剪辑员伸手把小男孩从车前往后拉一步。
- `black_frame/s02_shot_05`：世界恢复，汽车擦着小男孩急刹，妈妈一把抱住孩子大哭。
- `black_frame/s02_shot_06`：林默站在人群外，看着刚才剪辑员出现的位置，意识到不是奇迹。

## s03 办公室删掉伤人话
- `black_frame/s03_shot_01`：白天办公室，林默坐在工位上心不在焉，玻璃隔断后两个同事激烈争执。
- `black_frame/s03_shot_02`：同事举起杯子，脸涨红，嘴唇即将说出一句伤人的话。
- `black_frame/s03_shot_03`：黑帧内部，同事嘴边的空气出现一小段半透明声波状删减痕迹，被无形力量选中。
- `black_frame/s03_shot_04`：黑帧内部，剪辑员用细长时间轴工具划过嘴边的声波状删减痕迹，痕迹消散。
- `black_frame/s03_shot_05`：世界恢复，同事张了张嘴却沉默，放下杯子转身离开。
- `black_frame/s03_shot_06`：林默隔着玻璃盯着同事背影，开始理解黑帧会剪掉不可挽回的话。

## s04 餐厅离婚协议消失
- `black_frame/s04_shot_01`：夜晚小餐厅，林默坐在窗边吃饭，窗内另一桌夫妻沉默对坐。
- `black_frame/s04_shot_02`：夫妻桌上压着一份文件，两人都没有动筷，气氛僵硬。
- `black_frame/s04_shot_03`：黑帧内部，餐厅所有人静止，桌上的文件被剪辑员轻轻抽走。
- `black_frame/s04_shot_04`：世界恢复，夫妻继续吃饭，桌上文件不见，他们像忘了刚才的沉默。
- `black_frame/s04_shot_05`：林默的筷子停在半空，意识到黑帧不只救命，也会剪掉决定。

## s05 写笔记等不来
