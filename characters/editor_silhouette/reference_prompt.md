# 黑帧剪辑官 (Film Editor Officer) 角色参考图提示词

## 概念设定

- **本质**：存在于“黑帧”静止空间中的世界规则执行者，如同穿梭在时间切片中的神秘剪辑官。
- **形态特征**：
  - **体态**：拥有与林默完全相同的真实人体骨骼、修长身材与写实厚涂动漫质感。
  - **服装**：现代深炭灰长款风衣/工装大衣，深色高领内搭，修长手掌戴深色哑光手套。
  - **面部**：头部处于风衣兜帽或深邃冷感阴影之中，面部自然隐于深黑虚空中，无任何怪物五官，冷静、神秘、克制。
  - **专属工具**：手持银黑色细长时间轴刻度裁刀（Timeline Scissor Blade），散发微弱的冷白/冰蓝切口光芒。
- **画风规范**：
  - 与林默、许知遥 100% 同次元的电影级写实厚涂动漫风格（Cinematic anime style, Makoto Shinkai lighting, Studio Chizu / Psycho-Pass realism）。
  - 低饱和冷灰蓝色调、阴天漫射光、胶片颗粒质感。
  - 9:16 竖屏电影构图。

## 提示词模版 (Prompt)

```text
Cinematic anime style film still, 9:16 vertical ratio. A mysterious film editor officer standing in a quiet cold blue-grey anime room.
```
