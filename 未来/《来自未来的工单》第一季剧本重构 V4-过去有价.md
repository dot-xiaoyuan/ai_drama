# 《来自未来的工单》第一季剧本重构 V4

## 季名

**《过去有价》**

## 一句话故事

2026 年，普通上班族林默开始收到来自 2046 年的兼职订单。未来的人付钱，让他在今天完成一些看似无意义的小动作。林默最初以为自己在赚外快，后来发现：未来已经把“过去的选择”做成了一座交易市场，而他正在一点点卖掉自己的自由意志。

---

# 一、V4 核心判断

V3 的方向是对的：故事不能跑成“穿越救妹妹”，必须始终围绕最初那个最值钱的脑洞：

> 未来为什么要花钱购买我现在的一个小动作？

V4 在 V3 基础上做三处加强：

1. **妹妹林夏保留，但不能成为主线目标。**  
   她的作用是让林默第一次意识到：当未来开始竞价你在乎的人时，所谓“未来数据”会变成一种情感勒索。

2. **未来林默不做终极反派。**  
   他是这套系统最强的辩护者。他相信 FWO 虽然肮脏，但比完全无知的人类更有效率。

3. **EP10 的高潮不是“拒绝一个亿”。**  
   而是林默拒绝让“未来市场继续拥有出题权”。他不按发送，不是因为他证明了不发送一定更好，而是因为他终于接受：没有被未来计算过的人生，才是真正的未来。

---

# 二、世界观铁律

## 1. 未来只能发送信息

未来不能把人、物、武器、药物送回过去。

它只能发送：

- 指令
- 预测
- 数据报告
- 金融策略
- 文件、日志、坐标、时间点

钱不是从未来穿越回来的。未来提供的是“如何在当下合法获得这笔钱”的交易路径，FWO 自动执行后支付给林默。

## 2. FWO 不创造未来，只竞价过去

每一个未来版本都来自当前现实的不同演化。

它们无法直接控制 2026。

它们只能出价，请过去的人完成某个动作。

真正按下按钮的人，仍然是林默。

## 3. 未来报告真实，但不完整

FWO 展示的数据不是假数据。

但发单人可以选择展示哪些指标。

例如：

```text
存活人数：+1
```

可能同时隐藏：

```text
事故死亡：+4
永久伤残：+19
某公司垄断指数：+12%
```

这条规则是中期反转的核心。

## 4. 拒绝工单不会惩罚林默

FWO 不是神，也不是系统。

拒绝以后，现实只是照常前进。

这让故事更现实，也让林默的每一次接受更像真正的选择，而不是被游戏规则驱赶。

# 三、主角弧光

## 林默

27 岁，普通产品经理。

他不是天选之子，也不是圣人。

他的初始欲望很具体：

- 想多赚点钱
- 想证明自己不是毫无价值
- 想在平庸生活里抓住一次“只有我知道真相”的优越感

第一季他的变化不是“从自私到正义”。

而是：

> 从相信“更好的结果可以被计算出来”，到接受“人必须在不知道全部结果的情况下负责”。

## 林夏

22 岁，林默的妹妹。

她不是待拯救的奖杯。

她的功能是戳破林默的控制欲。

林默越被 FWO 训练成“用数据判断未来”，越容易把妹妹也当成一个需要优化的变量。

林夏必须有自己的判断：

> “你不是在保护我。你是在害怕你自己承担不了后果。”

## 未来林默

47 岁。

FWO 早期核心参与者之一。

他不是疯子。

他甚至比现在的林默更理性。

他的立场：

> 人类每一天都在因为无知做出错误选择。FWO 至少让未来的代价提前出现。

他真正可怕的地方不是邪恶。

而是他已经无法忍受“未知”。

# 四、第一季结构

单集建议 70～100 秒。

不要按“固定镜头数”写剧本。正确顺序是：

```text
剧情目的
→ 情绪变化
→ 动作连续性
→ 镜头拆分
```

每集必须具备：

1. 一张奇怪工单
2. 一个具体执行动作
3. 一个巨大未来反馈
4. 一个新规则或新问题

任何一集如果拿掉 FWO 仍然基本成立，就要重写。

# 五、分集大纲

## EP01《最后一瓶水》

林默深夜加班，收到第一张 FWO 工单。

```text
2046-A17
23:40 前
购买公司楼下自动售货机最后一瓶矿泉水。
不要打开。
报酬：¥200
```

他觉得是诈骗，但六分钟赚 200 元的诱惑太低成本。

他下楼，发现售货机里真的只剩最后一瓶水。

买下。

到账。

几秒后：

```text
正在重新计算未来……
2046-A17
存活人数：+1
```

林默看着手里的水。

旁白：

> “我只是买了一瓶水。”
>
> “二十年后，为什么会多活一个人？”

**本集钩子：** 一个毫无意义的小动作，真的改变了未来。

---

## EP02《那个人本来会死》

第二张工单：

```text
08:10 前
把昨天那瓶水放在地铁 C 口第三张长椅。
报酬：¥500
```

林默开始验证。他在瓶盖画线，远处观察。

一个外卖骑手拿走水，停下来喝了几口，因此比原路线晚了几十秒。

中午，本地新闻推送：

```text
某路口车辆失控，5 人死亡。
```

FWO 报告：

```text
原未来死亡人数：6
当前死亡人数：5
```

林默理解了第一瓶水的意义。

但新问题更大：

> “二十年后的人，怎么会知道他今天几点经过这里？”

**本集钩子：** 未来不是在预测大事件，而是在定位蝴蝶效应源头。

## EP03《今天别上班》

第三张工单：

```text
今日 09:00 前
不要进入公司。
报酬：¥3,000
```

林默第一次几乎没有犹豫。

公司演示因为他缺席出错，技术同事临时改方案，在白板上留下一个林默看不懂的结构图。

未来报告：

```text
某通信技术成熟时间：
2042 → 2031
提前 11 年
```

林默意识到：未来购买的不只是“救人”，也包括技术、商业、权力。

结尾新工单：

```text
明日 16:00 前
擦掉那块白板。
报酬：¥800
```

**本集钩子：** 一个普通人的缺席，能推动一项技术提前十一年。

**本集钩子：** 未来不是一个声音，而是一场竞争。

七秒五十万，反而让他害怕。

```text
B09
```

```text
ORDER CLOSED
WINNER：B09
```

这不是奖励。

这是出价。

**本集钩子：** 未来正在竞拍他今天的七秒钟。

林默尝试回复 UNKNOWN。

## EP08《一千万，让我骗妹妹》

林夏给林默发消息。

她拿到一个外地项目机会，第二天坐高铁出发。

FWO 出现两张工单。

```text

明早 08:00 前，让林夏取消行程。
报酬：¥0
```

```text

不要干涉林夏行程。
```

```text
LIN XIA

```

> “你自己决定吧。”

林夏正常去了。

没有车祸，没有爆炸，什么都没发生。

但 B09 信号强度暴涨。

林默意识到：未来竞拍的不一定是在避免灾难。它们也可能只是需要某个人，在二十年后出现在某个位置。

妹妹不是“要救的人”。

她也是被市场定价的变量。

**本集钩子：** 当未来购买你身边的人，你还敢相信它给你的数据吗？

## EP09《为什么我是第一名》

林默整理所有订单。

矿泉水。

不上班。

白板。

电梯七秒。

删除邮件。

妹妹行程。

表面上毫无关联。

但所有指标都指向同一个底层项目：

```text
TEMPORAL INFORMATION PROTOCOL
时序信息协议
```

这些互相竞争的未来有一个共同点：

它们都需要 FWO 最终诞生。

林默追到源头事件：

```text
2026.09.17
FWO 客户端异常崩溃
产生无法解释的数据日志
```

这段日志被林默转交给技术同事周祁。

十一年后，逆向时序通信第一次成功。

也就是说：

> 20 年后的未来能给今天发工单，是因为今天的林默把未来发来的东西，交给了未来技术的发明者。

完整因果圈闭合。

结尾第一次收到：

```text
2046-LM
发单人：LIN MO
```

未来的自己。

**本集钩子：** 林默最值钱，不是因为他能改变未来，而是因为他站在 FWO 诞生的源头。

## EP10《一个亿，按下发送》

47 岁的林默第一次出现。

他不疯，也不邪恶。

他只是很累。

他给年轻林默看 FWO 的另一面：

- 有些事故被避免
- 有些药物提前出现
- 有些战争没有发生
- 有些原本该死的人活到了 2046

未来林默：

> “你看到的是一群人拿钱买过去。”
>
> “我看到的是，人类第一次可以在犯错之前收到通知。”

年轻林默问：

> “那为什么要竞价？”

未来林默：

> “因为改变过去的机会有限。”
>
> “有人想救一百个人。”
>
> “有人想救自己的孩子。”
>
> “有人想让自己的公司赢。”
>
> “你告诉我，谁应该排在前面？”

最终订单出现：

```text
2026.09.17
17:42 前
将 FWO 崩溃日志发送给：周祁
报酬：¥100,000,000
```

页面第一次不展示美好未来，也不展示灾难数据。

只展示一句：

```text
保持 FWO 存在。
```

UNKNOWN 的最后消息：

```text
不要发送。
报酬：¥0
```

17:41。

林默坐在电脑前。

邮件已经写好。

附件：

```text
FWO_LOG
```

发送按钮就在面前。

竞价不断上涨。

```text
1 亿
1.2 亿
2 亿
3.7 亿
```

最后几乎所有未来都加入 `SEND`。

只有 UNKNOWN 没有报价能力。

林默终于明白：

> 它们争的是哪一个未来赢。
>
> 但没有任何既得利益者希望游戏消失。

倒计时最后两秒。

林默没有按发送。

他删除附件，关闭邮件。

手机疯狂震动。

```text
A17 SIGNAL LOST
B09 SIGNAL LOST
F77 SIGNAL LOST
```

2046-LM 最后问：

> “你知道你放弃了多少个已经被证明更好的未来吗？”

林默：

> “不知道。”

未来林默：

> “那你还敢选？”

林默：

> “以前不敢。”
>
> “所以才一直听你们的。”

连接即将断开。

林默看着屏幕。

> “可如果所有答案都提前写好了——”
>
> “那今天还有什么用？”

FWO 页面最后显示：

```text
FUTURE STATUS：UNKNOWN
```

这一次，UNKNOWN 不再是神秘账号。

而是真正的未知。

黑屏。

第一季结束。

# 六、EP01 可拍剧本骨架

## 目标时长

80～90 秒。

## 情绪线

疲惫 → 好奇 → 嘲笑 → 起疑 → 确认异常 → 不安。

## 剧本

### 0～8 秒：办公室深夜

空办公室。

电脑屏幕还亮着。

林默趴在工位前改 PPT。

键盘声停一下，又继续。

手机震动。

他没看。

手机又震。

旁白：

> “那天晚上，我收到了一份来自二十年后的兼职。”

### 8～20 秒：第一张工单

林默拿起手机。

屏幕冷光照到脸上。

后期 UI：

```text
FWO
Future Work Order

来源：2046-A17
报酬：¥200
```

林默皱眉。

滑动页面。

UI：

```text
23:40 前
购买公司楼下自动售货机最后一瓶矿泉水。
不要打开。
```

林默低声：

> “诈骗现在都这么拼了吗？”

### 20～32 秒：决定下楼

他看时间。

```text
23:34
```

再看报酬。

```text
¥200
```

他看向办公室门口。

空无一人。

他笑一下，带着自嘲。

> “六分钟，两百块。”
>
> “行，我看看你怎么骗。”

他起身。

### 32～48 秒：去售货机

走廊冷光。

电梯提示音。

一楼大厅。

这段不急，给空间。

让观众感到公司楼里只剩他一个人。

声音桥：

手机倒计时轻微震动声，延续到售货机区域。

### 48～62 秒：最后一瓶水

售货机亮着。

里面真的只剩最后一瓶矿泉水。

林默停住。

这一次不要马上扫码。

给他 1～2 秒反应。

他看手机。

再看售货机。

脸上的嘲笑消失一点。

扫码。

购买。

“咚。”

水掉下来。

### 62～73 秒：到账

林默弯腰取水。

手机震动。

UI：

```text
工单完成
+¥200.00
```

林默盯着到账通知。

他本来想笑。

但笑到一半停住。

### 73～88 秒：未来差异

手机再次跳转。

UI：

```text
正在重新计算未来……
```

几秒。

```text
2046-A17
存活人数变化：+1
```

大厅很安静。

林默看看手机。

又看看手里的水。

旁白：

> “我只是买了一瓶水。”
>
> “二十年后，为什么会多活一个人？”

黑屏。

# 七、后续拆镜原则

1. 手机 UI 全部后期叠加，不交给视频模型生成文字。
2. 一个视频生成片段只负责一个连续动作。
3. 对话场不要每 5 秒换地点。用正反打、手部、手机、侧脸维持同一场戏连续性。
4. 每集结尾不要都用“震惊黑屏”。结尾类型要轮换：
   - 认知反转
   - 新规则
   - 情绪停顿
   - 静物画面
   - 未完成选择
5. 每一集都必须能回答：
   - 这张工单为什么奇怪？
   - 林默执行了什么具体动作？
   - 未来反馈为什么巨大？
   - 这一集新增了哪一层 FWO 规则？

# 八、V4 与旧版最大差异

旧版后半段容易变成：

```text
救妹妹
对抗未来林默
阻止灾难
```

V4 后半段始终围绕：

```text
未来是否有资格购买现在的选择？
```

妹妹、未来林默、UNKNOWN 都只是把这个问题推向更私人、更尖锐的位置。

第一季最后不是证明 FWO 错了。

而是林默拒绝把自己的人生交给一套“看起来总能算出更优解”的系统。
