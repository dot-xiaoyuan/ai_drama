# 《黑帧》小样复盘 V1

## 本轮小样结论

本轮两条视频只证明 Seedance 通路可用，不证明美术方案可用。

### `black_frame/s02_shot_01`

输出问题：

- 色彩偏明亮、偏商业、偏偶像剧，和参考图的灰蓝低饱和风格不一致。
- 林默外貌和服装偏年轻偶像感，缺少“普通白领、疲惫、清瘦、迟钝空洞”的人物锚点。
- 因为使用了 `--reference-mode none`，模型没有得到任何视觉锚点，跑偏是预期风险。

处理结论：

- 不作为正式素材使用。
- 下一轮至少使用一张低风险场景参考图锁定色彩。
- prompt 必须明确禁止“清爽偶像剧、商业广告感、潮流男主”。

### `black_frame/s13_shot_06`

输出问题：

- “冲向记忆光带”被模型理解成飞扑或悬浮，动作失控。
- 记忆光带过亮，容易变成魔法/超能力视觉。
- 黑帧空间虽然接近，但动作语义过强，不能作为高潮镜头基准。

处理结论：

- 不作为正式素材使用。
- 下一轮把动作改成“站稳、微微前倾、伸手”，禁止飞、跳、漂浮、奔跑。
- 记忆元素只做低亮度裂缝或画面边缘暗银色痕迹，主要交给后期。

## 下一轮小样策略

1. 不再使用 `reference-mode none` 做风格验收。
2. 不再把整目录参考图全部塞给 Seedance，改用 `reference_images` 白名单。
3. 人物参考图触发隐私风控前，先用文字锚点控制人物，不硬撞完整人物参考图。
4. 每条小样只测试一个变量：
   - P1 测现实场景色彩和人物气质。
   - P2 测黑帧动作是否克制。
5. 只有两条都满足验收标准，才继续生成下一批。

## 下一轮推荐命令

```bash
.venv/bin/python main.py generate black_frame/s02_shot_01
.venv/bin/python main.py generate black_frame/s13_shot_06
```

这两个 shot 已经写入 `reference_images` 白名单，所以不需要再加 `--reference-mode scene-only` 或 `--reference-mode none`。

## 下一轮验收标准

### P1 十字路口

- 画面接近参考图：阴天、灰蓝、低饱和、真实城市质感。
- 林默是疲惫普通白领，不是偶像剧男主。
- 只是在等红灯，不提前发生救人、奔跑、车祸。

### P2 最终黑帧伸手

- 林默双脚在地面上。
- 只是站稳后伸手，不飞、不跳、不漂浮、不扑向镜头。
- 记忆元素低亮度、克制，不像魔法光带。
- 黑帧空间暗、冷、静止，不能变动作片。
